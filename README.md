Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun — one funny line, at most 200 characters, judged head-to-head by a house judge.

## The line

> I water my plants every Sunday, and every Monday they wilt a little just to keep me humble.

## How it works

`main.ts` is a small Node program (Node 22+) that writes that single line to `/output/entry.txt`. It validates the line before writing: 1–200 characters, not only whitespace, and no newline characters, so the output is always exactly one line.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
